## 📌 Описание проекта

Данный проект представляет собой полноценный сквозной цикл разработки и эксплуатации (End-to-End DevOps Pipeline) для веб-приложения на базе **FastAPI**. Проект демонстрирует реализацию концепций **Infrastructure as Code (IaC)**, автоматизацию конфигураций, контейнеризацию, оркестрацию и наблюдаемость (Observability):

1. **Разработка и тестирование**: Микросервис на FastAPI с автоматизированным покрытием тестами через `pytest`.
2. **Контейнеризация**: Сборка легковесного и безопасного образа с использованием Multi-Stage `Dockerfile` (запуск от имени non-root пользователя).
3. **IaC (Инфраструктура как код)**: Подготовка целевой инфраструктуры с помощью **Terraform**.
4. **Управление конфигурациями**: Автоматизация настройки серверов и хостов через **Ansible Playbook**.
5. **Оркестрация**: Развёртывание и масштабирование приложения в кластере **Kubernetes** (`Deployment` и `Service`).
6. **Мониторинг**: Сбор метрик сервиса с помощью **Prometheus**.
7. **CI/CD**: Автоматизированная валидация кода и сборка артефактов через **GitHub Actions**.

---

## 🛠️ Стек технологий

- **Backend:** Python 3.12+, FastAPI, Uvicorn
- **Тестирование:** Pytest, HTTPX
- **Контейнеризация:** Docker (Multi-stage build)
- **Оркестрация:** Kubernetes (K8s)
- **Управление конфигурациями:** Ansible
- **Инфраструктура как код (IaC):** Terraform
- **Мониторинг:** Prometheus
- **CI/CD:** GitHub Actions
